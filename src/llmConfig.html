LLM API Configuration

LLM Setup

Configure an LLM to power form filling. Use any OpenAI-compatible API, or a local model via Ollama.

OpenRouter provides access to many models through a single API. Get a key at openrouter.ai/keys and use https://openrouter.ai/api/v1/chat/completions as the API URL.

Filling runs as a loop: the model is shown the page as a person sees it, answers with a batch of actions (tool call), the extension performs them and shows the page again, and the model fixes or finishes. Model calls per fill caps that: one call fills a plain form, a form that changes while it is filled takes one more per change. Reasoning effort applies to OpenRouter (and OpenAI reasoning models); "low" is fine for most forms.
