LLM Setup

Configure an LLM to power form filling. Use any OpenAI-compatible API, or a local model via Ollama.

OpenRouter provides access to many models through a single API. Get a key at openrouter.ai/keys and use https://openrouter.ai/api/v1/chat/completions as the API URL.
