LLM Setup

Configure an LLM to power form filling. Use any OpenAI-compatible API, or a local model via Ollama.

OpenRouter provides access to many models through a single API. Get a key at openrouter.ai/keys and use https://openrouter.ai/api/v1/chat/completions as the API URL.

Filling runs as a short loop: the model receives the form's fields, answers with a batch of actions (tool call), the extension executes them and reports back what the page did, and the model fixes or finishes. Turn budget caps the number of model calls per fill (2 to 4 is typical). Reasoning effort applies to OpenRouter (and OpenAI reasoning models); "low" is fine for most forms.
